# Telegram channel notification

Вертикальное изображение для сообщения о расширении географии КнопкА. Формат
4:5 и широкие внутренние поля рассчитаны на Telegram-превью без обрезания
крайних карточек. На изображении намеренно нет рекламного текста: подпись
публикуется отдельно в Telegram.

## Состав стран

Список текущих стран проверен в production D1 `servers` 01.10.2026:

- Германия (`DE`), Франция (`FR`), Нидерланды (`NL`) — `active = 1`;
- Россия и YC-серверы исключены;
- Польша (`PL`) и Великобритания (`GB`) — новые направления.

## Финал

- `tg-notification-01-row.png` — единая вертикальная композиция в порядке
  `FR → DE → PL → GB → NL`.

Все карточки стоят вертикально и имеют светлый фон. Флаги отделены тонкой серой
рамкой. Польша и Великобритания немного крупнее остальных, но уменьшены
относительно предыдущей итерации и не перекрывают друг друга. Перекрытие каждой
другой пары не превышает 20% площади меньшей карточки.

Финальное изображение имеет размер 1254×1568 px, цветовой режим sRGB и
использует палитру Design 2.0: `#fbf7f2`, `#fffdf9`, `#f5dfd2`, `#dcecff`.

## Источники

Фоновая пластина сгенерирована встроенным `imagegen` по визуальным референсам
`Ideas/site-01.png` и `site/assets/hero-workspace.png`. Карточки и точные флаги
накладываются детерминированно из HTML/CSS и локальных SVG, поэтому их геометрия
не зависит от генеративной модели. Финальный PNG воспроизводится командой:

```bash
./source/compose.sh
```
