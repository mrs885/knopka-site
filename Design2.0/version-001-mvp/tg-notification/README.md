# Telegram channel notifications

Три квадратных варианта изображения для сообщения о расширении географии
КнопкА. На изображениях намеренно нет рекламного текста: подпись публикуется
отдельным сообщением в Telegram.

## Состав стран

Список текущих стран проверен в production D1 `servers` 01.10.2026:

- Германия (`DE`), Франция (`FR`), Нидерланды (`NL`) — `active = 1`;
- Россия и YC-серверы исключены;
- Польша (`PL`) и Великобритания (`GB`) — новые направления.

## Варианты

- `tg-notification-01-row.png` — единый ряд: три текущих небольших флага и два
  новых крупных;
- `tg-notification-02-cards.png` — текущие страны собраны в малую группу, новые
  вынесены на две крупные карточки;
- `tg-notification-03-routes.png` — три текущих узла визуально соединяются с
  двумя новыми направлениями;
- `preview-all.png` — общий лист для быстрого сравнения.

Все финальные изображения имеют размер 1254×1254 px и используют палитру
Design 2.0: `#fbf7f2`, `#fffdf9`, `#f5dfd2`, `#dcecff`.

## Источники

Фоны с пустыми карточками сгенерированы встроенным `imagegen` по визуальным
референсам `Ideas/site-01.png` и `site/assets/hero-workspace.png`. Точные флаги
накладываются из локальных SVG, поэтому их геометрия не зависит от генеративной
модели. Финальные PNG воспроизводятся командой:

```bash
./source/compose.sh
```
