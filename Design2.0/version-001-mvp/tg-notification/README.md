# Telegram channel notifications

Пять вертикальных вариантов изображения для сообщения о расширении географии
КнопкА. Формат 4:5 и широкие внутренние поля рассчитаны на Telegram-превью без
обрезания крайних карточек. На изображениях намеренно нет рекламного текста:
подпись публикуется отдельно в Telegram.

## Состав стран

Список текущих стран проверен в production D1 `servers` 01.10.2026:

- Германия (`DE`), Франция (`FR`), Нидерланды (`NL`) — `active = 1`;
- Россия и YC-серверы исключены;
- Польша (`PL`) и Великобритания (`GB`) — новые направления.

## Варианты

- `tg-notification-01-row-a.png` — спокойная симметричная дуга;
- `tg-notification-01-row-b.png` — плотный веер с сильным разворотом;
- `tg-notification-01-row-c.png` — широкий почти фронтальный полукруг;
- `tg-notification-01-row-d.png` — плавающая дуга с усиленной глубиной;
- `tg-notification-01-row-e.png` — самый контрастный вариант с выраженным
  светлым контуром флагов;
- `preview-row-variants.png` — общий лист для быстрого сравнения.

Во всех версиях порядок одинаков: `FR → DE → PL → GB → NL`. Польша и
Великобритания выдвинуты вперёд и сделаны крупнее; Германия и Нидерланды
занимают средний план, Франция — дальний. Тёмные карточки и контур отделяют
белые области флагов от фона.

Все финальные изображения имеют размер 1254×1568 px, цветовой режим sRGB и
используют палитру Design 2.0: `#fbf7f2`, `#fffdf9`, `#f5dfd2`, `#dcecff`.

## Источники

Фоновая пластина сгенерирована встроенным `imagegen` по визуальным референсам
`Ideas/site-01.png` и `site/assets/hero-workspace.png`. Карточки и точные флаги
накладываются детерминированно из HTML/CSS и локальных SVG, поэтому их геометрия
не зависит от генеративной модели. Финальные PNG и preview воспроизводятся
командой:

```bash
./source/compose.sh
```
