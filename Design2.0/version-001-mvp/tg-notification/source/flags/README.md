# Flag sources

- `gb.svg`: Wikimedia Commons, `Flag_of_the_United_Kingdom.svg`, downloaded
  2026-10-01 from
  <https://commons.wikimedia.org/wiki/Special:Redirect/file/Flag_of_the_United_Kingdom.svg>.
- `de.svg`, `fr.svg`, `nl.svg`, `pl.svg`: deterministic local stripe vectors
  retained from the original artwork source set.

Flags are rendered by Chromium from these SVG sources; they are not generated
by an image model.
