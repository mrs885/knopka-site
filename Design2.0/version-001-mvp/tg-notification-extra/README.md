# Telegram notification extra

Отдельная брендированная надстройка над утверждённой базовой нотификацией из
`../tg-notification/`. Базовая папка и её файлы не изменяются.

## Финал

- `tg-notification-extra-01.png` — исходная композиция стран с круглым логотипом
  КнопкА на верхней стене, без дополнительного текста.

Формат: 1254×1568 px, sRGB, без прозрачности. Логотип взят из предоставленного
Ромой JPEG без изменений. Центральная кнопка вырезана по круглому контуру, а
зелёные внешние дуги и свечение вынесены в отдельный screen-слой: исходный
серый/чёрный фон вокруг знака в композицию не попадает. Источник и его checksum
описаны в `source/assets/README.md`.

## Базовый слой

Композиция использует неизменённый файл
`../tg-notification/tg-notification-01-row.png` из commit `a227399`.
Контрольная сумма зафиксирована в `source/base.sha256` и проверяется перед каждым
рендером.

## Воспроизведение

```bash
./source/compose.sh
```
