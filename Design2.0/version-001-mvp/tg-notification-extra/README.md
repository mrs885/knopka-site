# Telegram notification extra

Отдельная брендированная надстройка над утверждённой базовой нотификацией из
`../tg-notification/`. Базовая папка и её файлы не изменяются.

## Финал

- `tg-notification-extra-01.png` — исходная композиция стран с полупрозрачным
  логотипом КнопкА на верхней стене и foreground-титром «КнопкА ВПН» внизу.

Формат: 1254×1568 px, sRGB, без прозрачности. Логотип воспроизводит канонический
production-знак из корневого `index.html`: зелёный квадрат `#00c853`, радиус
8/36 от стороны, чёрная буква `A` и системная sans-serif типографика.

## Базовый слой

Композиция использует неизменённый файл
`../tg-notification/tg-notification-01-row.png` из commit `a227399`.
Контрольная сумма зафиксирована в `source/base.sha256` и проверяется перед каждым
рендером.

## Воспроизведение

```bash
./source/compose.sh
```
