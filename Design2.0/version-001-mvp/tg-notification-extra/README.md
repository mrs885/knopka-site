# Telegram notification extra

Отдельная брендированная надстройка над утверждённой базовой нотификацией из
`../tg-notification/`. Базовая папка и её файлы не изменяются.

## Финал

- `tg-notification-extra-01.png` — исходная композиция стран с мягко встроенным
  круглым логотипом КнопкА на верхней стене и выпуклым мраморным 3D-титром
  «КнопкА ВПН» внизу.

Формат: 1254×1568 px, sRGB, без прозрачности. Логотип взят из предоставленного
Ромой JPEG без изменений и встроен в стену радиальной маской с плавным переходом.
Источник и его checksum описаны в `source/assets/README.md`. Нижняя надпись
остаётся редактируемым HTML/CSS-текстом; мраморная поверхность, светлая выпуклая
кромка и тёмная экструзия формируются детерминированно.

## Базовый слой

Композиция использует неизменённый файл
`../tg-notification/tg-notification-01-row.png` из commit `a227399`.
Контрольная сумма зафиксирована в `source/base.sha256` и проверяется перед каждым
рендером.

## Воспроизведение

```bash
./source/compose.sh
```
