Единственный визуальный эталон — `Ideas/site-01.png`. Сохранены его изображения,

Изменения: заголовок «Доступ ко всем приложениям» и три демонстрационных
отзыва со звёздами. Каждая карточка обозначена «Пример отзыва», весь раздел —
«не реальные отзывы». Это образцы текста, а не опубликованные отзывы клиентов.

## Граница этой итерации

Текущая правка — **визуальные макеты site**. `source/` и `template/` пока
содержат HTML/CSS предыдущего MVP и **не соответствуют новым PNG**. Они
сохранены для следующей итерации вёрстки, а не выдаются за исходники новых
макетов. Для просмотра актуального результата открывать `preview.html`.

Mobile — композиционный эскиз, в том числе с мелкими трёхколоночными карточками;
окончательная читаемость при 390 CSS px и перенос карточек проверяются при
вёрстке. Генеративное редактирование не гарантирует пиксельную идентичность
всех нетронутых областей и точность мелкого текста. Финальные надписи следует
верстать настоящим текстом.

Остальные поверхности (`app-site`, `tg-ad`, `tg-bot`) в этой правке не менялись.

## Инструкции генерации

Использован встроенный imagegen, не API/CLI.

Desktop: точечное редактирование `site-01.png`; сохранить весь холст, фотографии,
иконки, чёрные кнопки, типографику, цвета и меню. Заменить только заголовок на
«Доступ ко всем приложениям» в две строки и заполнить три существующие
карточки пятью звёздами и явно обозначенными примерами отзывов.

Примеры текста карточек:

1. «Подключилось быстро. Видео смотрю без постоянных переключений.»
2. «На телефоне и ноутбуке удобно. Российские сайты тоже открываются.»
3. «Рома помог с настройкой. Всё объяснил простыми словами.»

Mobile: адаптировать полученный desktop, сохранив все секции, фотографии,
иконки сервисов и надписи; не добавлять новые блоки и синие CTA. Сохранить
явную маркировку демонстрационных отзывов.
