# App-site assets

В MVP отдельные растровые иллюстрации платёжных состояний намеренно не
создавались. В презентационных макетах используются контролируемые CSS-формы,
а в `../template/` — явные пустые placeholders.

Финальные иллюстрации для `found`, `pending`, `notfound` и `error` относятся к
следующей итерации.
