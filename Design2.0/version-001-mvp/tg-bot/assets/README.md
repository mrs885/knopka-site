# Telegram bot assets

`phone-hands.png` создан встроенным imagegen как светлый квадратный фон без
текста и логотипов. Все надписи и служебные плашки наложены в `../source/`.

Краткий prompt: две руки держат современный телефон в светлом тёплом
интерьере; на экране только абстрактное голубое свечение подключения; свободная
область сверху; без текста, логотипов, app icons и тёмной cyber-стилистики.
