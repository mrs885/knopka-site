# Telegram Ads assets

`hero-workspace.png` — локальная копия светлого hero-фона этой версии. Фон
создан встроенным imagegen без текста и логотипов; вся рекламная типографика
находится в `../source/` и остаётся редактируемой.

Краткий prompt: светлое домашнее рабочее место, ноутбук и телефон справа,
много свободного пространства, тёплая editorial-фотография, без людей,
текста, логотипов и fake UI.
