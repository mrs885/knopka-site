# Общие ассеты Design 2.0

## `app-button-black-a.png`

Прозрачный PNG `640×640` с исходной чёрной кнопкой приложения и зелёной
буквой A. Внешний зелёный ореол, декоративные дуги и квадратный фон удалены.
Серебристый обод является частью самой кнопки и сохранён.

Ассет вырезан детерминированно из присланного Ромой исходника без
генеративной перерисовки. Оригинал хранится в
`source/app-button-original.png`; его SHA-256 проверяется перед каждой сборкой.

Пересборка:

```bash
./build-app-button.sh
```
