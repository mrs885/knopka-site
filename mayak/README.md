# Mayak Networks — clean-room SEO reference

Эта папка — не зеркало сайта Mayak Networks. Она содержит только публичную
карту URL и технические метрики, необходимые для конкурентного анализа.

В репозиторий намеренно не сохраняются:

- тексты статей;
- HTML/CSS/JavaScript конкурента;
- изображения, шрифты и другие assets;
- формы, cookies или пользовательские данные.

## Обновить аудит

```bash
python3 mayak/update_audit.py
```

Скрипт читает публичный `sitemap.xml`, запрашивает страницы с ограниченной
параллельностью и создаёт:

- `data/site-map.json` — машиночитаемый inventory;
- `data/site-map.js` — те же данные для локальной панели без HTTP server;
- `data/summary.md` — компактную текстовую сводку.

Сохраняются URL, короткий title и только числовые/булевы технические признаки.
Тело страницы и meta description не записываются.

## Открыть локально

Можно открыть `mayak/index.html` двойным щелчком: данные подключены обычным
`<script>` и работают через `file://`.

Или запустить статический сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

После этого открыть:

```text
http://localhost:8080/mayak/
```

## Назначение

Inventory используется только для:

- группировки поисковых интентов;
- оценки глубины и свежести блога;
- анализа технического SEO;
- проектирования оригинального контента КнопкА.

Тексты будущих статей должны создаваться с нуля по REQ-002.
